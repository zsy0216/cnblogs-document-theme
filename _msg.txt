feat(v7.21): 移动端目录抽屉、宽表横滑、打印、代码折叠、续读、暗色跟随

移动端（<=860px 左栏本来就是隐藏的，手机上一直没有目录）：
- 左下角「目录」胶囊按钮 + 底部抽屉，内容克隆自桌面目录，不另起一套逻辑
- 滚动锁加在 html 上：iOS 对 body overflow:hidden 不生效
- 跨过 860px 断点自动关闭，否则桌面端会带着滚动锁打不开
- <=480px 正文 16px、留白收紧、隐藏触屏用不上的标题锚点

宽表：套 overflow-x 容器 + 首列 sticky。园方写死 width:100%，七列表格每列
只剩 110px、表头折成两行。只在真溢出（.qb-x）时才吸附，窄表不受影响；
分隔用 box-shadow 不用 border-right，否则横滑时首列宽度会跳。

超长代码块：>34 行折到 500px（手机 360px），底部按钮写总行数。
按钮放底部而不是工具条：读者滚到折叠处才发现截断，再滚回顶部找按钮等于白折。

续读记忆：按路径存 localStorage，load 后 60ms 恢复。带 #hash 不抢、已滚动
不抢、滚回顶部即清除、7 天过期、最多留 60 条。

暗色：订阅 prefers-color-scheme 的 change。原来只在加载时读一次，系统在
页面开着时切暗色，主题一动不动。手动选过的仍然优先，不被系统顶掉。

Markdown 补全：kbd / mark / details / 任务列表 / 脚注 / figure / dl / abbr / hr。
任务列表必须由脚本打标记：渲染器输出 <li><input checkbox>，园方仍画圆点。

打印：变量归零转白底黑字，外壳全隐藏；代码整段展开、pre-wrap 折行，
token 强制深色（那套配色是给深色底的，印白纸上几乎看不见）；
Prism 行号在纸上关闭 —— 它的行号是 absolute 定高，折行后会整体错位，
宁可这页不印也不能让读者照错位编号读代码。自建行号跟着块走，保留。

验证：新增 verify-v721.js 8 组 60 余条断言；verify-post / verify-code /
verify-defaults / verify-config / verify-bundle / min-parity / gen-deploy --check
全过。真实文章页复核：375px 无横向溢出、6 节目录抽屉正常、打印态代码深色可读。
