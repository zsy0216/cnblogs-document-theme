# 样式变量说明

在 `style.css` 文件最上方的 `:root` 中定义，修改以下变量即可全局换肤，无需改动其他 CSS。

## 背景色

| 变量 | 说明 | 默认值 |
| ---- | ---- | ------ |
| `--bg-page` | 页面底色（纯色浅灰，非渐变） | `#f5f6f8` |
| `--bg-card` | 卡片背景（所有白卡） | `#ffffff` |

## 主色

| 变量 | 说明 | 默认值 |
| ---- | ---- | ------ |
| `--accent` | 品牌主色（链接/按钮/高亮） | `#d05ce8` |
| `--accent-hover` | 悬停色 | `#c03ecf` |
| `--accent-light` | 浅色主色（背景块） | `rgba(208,92,232,.12)` |

## 文字色

| 变量 | 说明 | 默认值 |
| ---- | ---- | ------ |
| `--ink-title` | 标题（最深） | `#1f2329` |
| `--ink-body` | 正文（主要） | `#4a5568` |
| `--ink-meta` | 次要（日期/标签/统计） | `#a0aec0` |
| `--ink-link` | 链接色 | `#2b6cb0` |
| `--ink-link-h` | 链接悬停色 | `#2c5282` |

## 标签

| 变量 | 说明 | 默认值 |
| ---- | ---- | ------ |
| `--tag-bg` | 标签背景 | `#edf2f7` |
| `--tag-text` | 标签文字 | `#718096` |
| `--tag-hover-bg` | 标签悬停背景 | `#e2e8f0` |

## 卡片边框与阴影

| 变量 | 说明 | 默认值 |
| ---- | ---- | ------ |
| `--border-card` | 白卡边框 | `#eef0f2` |
| `--shadow-card` | 卡片默认阴影 | `0 2px 8px rgba(0,0,0,.04)` |
| `--shadow-card-hover` | 卡片悬停阴影 | `0 4px 16px rgba(0,0,0,.06)` |

## 圆角

| 变量 | 说明 | 默认值 |
| ---- | ---- | ------ |
| `--radius` | 统一圆角 | `12px` |
| `--radius-sm` | 小圆角 | `8px` |
