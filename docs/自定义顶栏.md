# 自定义顶栏

> v7.2 起顶栏**由脚本按配置渲染**，页首字段里只留一个空的 `.qb-nav` 外壳占位（首帧就是 59px 白条，内容填进去不跳动）。
> 改菜单 = 改 `LS_CONFIG.nav`，不用碰 HTML 结构。

---

## 一、菜单：改 `LS_CONFIG.nav.links`

页首字段里那个 `window.LS_CONFIG = {}` 就是入口，托管版与内联版都一样：

```js
window.LS_CONFIG = {
  nav: {
    brand: 'Ep流苏',                       // 品牌区文字
    home: 'https://www.cnblogs.com/你的博客名/',   // 点品牌区去哪
    logo: 'https://…jpg',                  // 留空 = 只显示文字
    mark: true,                            // 品牌区右侧的十字图形，false 关掉
    dark: true,                            // 是否显示暗色开关（🌙/☀️）
    links: [
      { t: '首页', h: 'https://…/' },
      { t: '归档', h: 'https://…/p/archive/2026/11' },
      { t: '分类', h: 'https://…/categories' },
      { t: '标签', h: 'https://…/tag' },
      { t: 'GitHub', h: 'https://github.com/xxx', b: 1 }   // b:1 = 新窗口打开
    ]
  }
};
```

| 字段 | 说明 |
|:---|:---|
| `t` | 菜单文字 |
| `h` | 目标地址，写相对路径也行（`/你的博客名/tag`） |
| `b` | `1` = 新窗口打开（带 `rel="noopener"`） |
| `on` | `1` = 强制高亮；不写则按当前地址自动高亮 |

`links` 是**整体替换**：写了就完全按这份渲染，不会和内置的 9 个菜单合并。只想删掉一项，就把它从数组里去掉。

**不写 `nav` 时**用内置默认（9 个菜单 + 品牌区 + 暗色开关），也是绝大多数人直接能用的样子。

> 内联形态的页首字段里带了一份**静态菜单**（`<nav class="qb-links">` 那一段）。
> 两种改法都有效：改 `LS_CONFIG.nav` 会重建，改静态那段则在没配 `nav` 时生效。详见[备选-内联安装](备选-内联安装.md)。

### 博客园可用的页面地址（实测 200）

| 菜单 | 格式 | 示例 |
|:---|:---|:---|
| 首页 | 博客名主页 | `https://<name>/` |
| 归档 | `/p/archive/YYYY/MM` | `https://<name>/p/archive/2026/11` |
| 分类 | `/categories` | `https://<name>/categories` |
| 标签 | `/tag` | `https://<name>/tag` |
| RSS | `/rss` | `https://<name>/rss` |
| 留言 | 站内信 | `https://msg.cnblogs.com/send/<名>` |
| 主页 | 管理页 | `https://home.cnblogs.com/u/<name>` |
| 管理 | 后台设置 | `https://i.cnblogs.com/settings/` |

归档只有按月地址，**没有总览页**；顶栏那个「归档」链接在归档页会被脚本自动改成最新月份，以后发文不用手改。见[归档时间线](功能-归档时间线.md)。

## 二、品牌区 logo

品牌区 = `.qb-brand`，里面可以并排放三样东西：图标、文字、右侧装饰图形。三样都由配置控制，不需要写 HTML。

| 想变成 | 怎么配 |
|:---|:---|
| 图标 + 文字 + 十字装饰（默认） | `logo: '…jpg'`、`brand: '名字'`、`mark: true` |
| 只要文字 | `logo: ''` |
| 不要右侧装饰 | `mark: false` |
| 只要图标 | `brand: ''`、`mark: false` |

细节：

- 图标尺寸固定 30px（小屏 24px），由 CSS 的 `.qb-logo` 控制；改大小要 `width` / `height` / `flex-basis` 三个值一起改
- 装饰十字的点缀色在 `.qb-logo .qb-logo-dot` 的 `fill`（暗色单独一档在 `body.qb-dark` 下）
- 元素间距由 `.qb-brand` 的 `gap` 控制（默认 9px）
- 小屏（≤860px）菜单改为**横向滑动**，logo 与暗色开关固定不动

想完全手写品牌区（比如放自己的 SVG），用[备选-内联安装](备选-内联安装.md)那份静态页首改写 `.qb-brand` 内部结构；CSS 对图片和内联 SVG 都做了适配，笔画用 `stroke="currentColor"` 就会跟着 hover 变色。

## 三、浏览器标签图标（favicon）

在**页首字段**里加一行：

```html
<link rel="icon" href="https://你的图床/图标.png" />
```

支持 `png / ico / svg / jpeg`。**只需要一行**，不要同时贴 `shortcut icon` + `icon` 两行。

原理：

1. 博客园会把页首 HTML 塞在 body 里的 `#page_begin_html`，而浏览器只认 `<head>` 里的 `<link rel=icon>`，所以脚本会自动把它搬进 `<head>`
2. 博客园自己会往 `<head>` 写 `favicon_v3_3.ico` / `.svg` 两个默认图标，脚本会把它们清掉，并用 `MutationObserver` 持续拦截（园方脚本可能在页面加载后几秒再塞回来）
3. 脚本给图标地址追加 `?v=6.20` 绕开浏览器 favicon 缓存。**换图后没变化的话，换个新的图片地址最快**（URL 变了浏览器就会重取）；同一个地址硬要刷新，得改脚本里的 `FAV_VER` 再重新构建
4. 建议用**正方形 PNG（32×32 或 64×64）**。JPEG 没有透明通道，深色标签栏上会出现白底方块，小尺寸下边缘还会糊

## 四、顶栏样式

都在 `css/theme-v7.css` 的「2. 自建顶栏」一节：

| 想改 | 改哪儿 |
|:---|:---|
| 高度 | `.qb-nav` 的 `min-height`（默认 58px，窄屏 52px）。**不要删这条**，页首外壳靠它撑住首帧高度 |
| 背景、描边 | `.qb-nav` 的 `background` / `border-bottom` |
| 菜单间距 | `.qb-nav-inner` 的 `gap` |
| 当前页高亮 | `.qb-links a.on` |
| 完整隐藏顶栏 | 删掉页首字段里的 `<div class="qb-nav" id="qb-nav">…</div>` 整行，并把 `LS_CONFIG.nav` 一起去掉 |

> **不要在 `.qb-links` 上加 `flex-wrap`**：会把顶栏撑成两行，破坏 `min-height` 定下的 59px 高度。
