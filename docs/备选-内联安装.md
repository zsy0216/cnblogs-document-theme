# 备选：三字段全内联安装

> **默认装法不是这个。** 正式形态是托管版（[README](../README.md) 的 4 步），改版只传一个 js。
> 这里讲的是「页面不发出任何主题请求」的全内联形态 —— 没有外部依赖，代价是每次改脚本都要重贴一次页脚。

---

## 一、什么时候选它

| | 全内联 | 托管（默认） |
|:---|:---|:---|
| 后台字段 | 贴 4 个（CSS / 页首 / 页脚 / 公告留空） | 贴 2 个 |
| 上传文件 | **0 个** | 1 个 js |
| 页面发出的主题请求 | **0 次** | 1 次（70 KB） |
| 改脚本逻辑 | 重贴一次页脚字段（37 KB） | 只传 js |
| 改样式 | 重贴一次 CSS 字段 | 只传 js |
| 博客园文件空间挂掉 | 不受影响 | 全站裸奔 |

只想让后台少一个外部依赖、或文件空间老出问题时选它。其余情况用托管。

---

## 二、生成四份文件

```bash
python _dev-tools/gen-deploy.py --mode inline
```

产物在 `dist/paste/inline/`：

| 文件 | 贴到哪 | 内容 |
|:---|:---|:---|
| `4-样式.css` | 页面定制 CSS 代码 | 完整主题样式（首行 `html{--qb-field:1}` 不要删） |
| `1-页首.html` | 页首 HTML 代码 | 静态顶栏（含菜单）+ `LS_CONFIG` + 归档页标记 |
| `2-页脚.html` | 页脚 HTML 代码 | **整段主题脚本**（压缩版，约 37 KB） |
| `3-公告.html` | 公告 | 只有一句注释，也可以直接把该字段清空 |

---

## 三、安装步骤

> ⚠️ **第 0 步**：设置 → 皮肤 → 选 **`Custom`（自定义）**，否则后面全都不生效。

1. **贴 CSS**
   设置 → 页面定制 CSS 代码 → 全选删除 → 粘贴 `4-样式.css` 全文 → 保存。
   这一步决定**首帧就是三栏**（三列宽度写在这份 CSS 里），不能省。

2. **贴页首**
   设置 → 页首 HTML 代码 → 全选删除 → 粘贴 `1-页首.html` 全文 → 保存。
   里面只有收藏夹图标、几条 `preconnect`、静态顶栏、`window.LS_CONFIG`，没有任何主题资源。

3. **贴页脚**
   设置 → 页脚 HTML 代码 → 全选删除 → 粘贴 `2-页脚.html` 全文 → 保存。
   **这是主题的全部脚本，内联在页面里**。保存后回编辑器看一眼结尾是不是 `})();` ——
   如果结尾被截断，说明字段长度不够。

4. **清空公告字段**（或粘贴 `3-公告.html`）
   公告改由 `LS_CONFIG.notice` 渲染，默认已内置原有文案，再填会重复。

5. **`Ctrl + F5`** 强刷。

> 三个字段都要**先删干净再贴**。留着旧内容是最常见的「改了没生效」原因：
> 旧 CSS 自带一套规则，会和新的叠在一起打架。

### 全内联形态换菜单

这个形态的菜单是**页首字段里的静态结构**（`<nav class="qb-links">` 那一段），
和托管版改 `LS_CONFIG.nav` 不同。两种改法都行：

- 改页首字段里的 `.qb-links`：复制一行增菜单、删一行减菜单，当前页高亮加 `class="on"`
- 或者在 `LS_CONFIG` 里写 `nav.links`：写了就按配置重建，覆盖静态那份

详细写法见[自定义顶栏](自定义顶栏.md)。

## 四、验收

| 检查项 | 期望 |
|:---|:---|
| 首屏出现时 | **直接是三栏**，没有「单列闪一下再变三栏」 |
| 右栏第一眼 | 公告 + 搜索/积分/排行**全都在**，不是先出公告再长出下面几张 |
| 顶部 | 白色导航条 59px，logo + 菜单 + 🌙 一开始就在 |
| 左栏 | 文章目录/列表已就位，带 160ms 淡入，位置不移动 |
| 归档页 | 直接是「全部归档」时间线，看不到博客园原生的按月列表 |
| 源码搜 `document-theme` | **0 处**（有 1 处说明还在走托管，页脚没贴对） |
| 控制台 | 无红色报错 |

## 五、排错

| 现象 | 原因 | 处理 |
|:---|:---|:---|
| 还是单列跳三栏 | CSS 字段没贴或没保存 | 搜源码有没有 `--qb-field` |
| 顶栏有但没样式 | CSS 字段贴了旧版 | 重新贴 `4-样式.css` |
| 右栏整块没出来 | 页脚字段没贴 / 被截断 | 页脚末尾应当是 `})();`，缺了就重贴 |
| 还是闪 / 切页要等一下 | 源码搜到 `document-theme`，说明页脚还是加载器的写法 | 重贴 `2-页脚.html`（整段脚本，不是一行引用） |
| 页面整体横移一下 | CSS 是旧的（没有 `scrollbar-gutter`） | 重新贴 `4-样式.css` |
| 归档页还是先看到普通列表 | 页首是旧的（没有 `qb-arc-page` 那段） | 重新贴 `1-页首.html` |
| 控制台报 `LS_CONFIG is not defined` | 页首里的配置段没贴全 | 重新贴 `1-页首.html` |
| 白屏超过 2.5 秒 | 脚本报错且 CSS 兜底也失效 | 控制台看报错；CSS 里的解锁兜底应保证 2.5s 内出现 |

---

## 六、回退到托管版

1. 页脚字段 → 全选删除
2. 页首字段 → 换成 `dist/paste/页首.html`（托管版那份，2.3 KB）
3. 上传 `dist/document-theme.js`
4. CSS 字段可以保留不动（两份 `样式.css` 内容相同）

反过来从托管回内联，照第三节重贴页脚即可。
