# 谁在用这套主题

主题是 MIT，装完不用打招呼。但如果你已经用上了，**欢迎登记到这里**。

两个目的：

1. 给后来的人一个「真实长什么样」的参照。README 里的截图是作者的站，别人改了强调色、换了字号、装了别的插件之后是什么效果，只有真站点能看出来。
2. 让我知道这套 CSS 在别的博客上有没有翻车。博客园的模板设置人人不同（有没有开 Markdown、有没有装代码高亮插件、公告里放了什么），差异比想象中大。

## 怎么登记

任选一种：

| 方式 | 步骤 |
|:---|:---|
| **提 issue**（推荐） | [新建 issue](https://github.com/zsy0216/cnblogs-document-theme/issues/new?template=showcase.yml)，模板里已列好字段，填完提交即可 |
| **在推广文下面留言** | 在[《给博客园换一身文档站皮肤》](https://www.cnblogs.com/zhangshuaiyin/)的评论区留地址，我看到就加 |
| **直接改这个文件提 PR** | 在上面的表格里加一行，格式随意，我来对齐 |

要填的就三样：**站点名、地址、一句话说明**。说明写你最想告诉别人的那点，例如：

- 「只把 `accent` 换成了蓝色」
- 「内联安装，没传 js 文件」
- 「和我自己的代码高亮插件打架，改了哪条选择器」
- 「移动端目录抽屉很好用」

有截图更好，但不必。

## 收录标准

**收**：能正常打开、主题完整生效（三栏 + 顶栏 + 左栏目录都在）、内容正常的个人技术博客。

**不收**：采集站、镜像站、纯广告站；以及装了主题但基本改回原样、或者只剩一个强调色的 —— 那样放上来对别人没有参考价值。

站点打不开会从表里去掉，不另行通知。

## 维护备注（给作者自己）

- issue 模板是 `.github/ISSUE_TEMPLATE/showcase.yml`，会自动打 `showcase` 标签。**仓库里要先手动建一个名为 `showcase` 的 label**，否则 GitHub 会静默忽略这个字段（不会报错，只是没标签）。
- 加新站点时同步三处：本文件的表格、README 的「谁在用」表格、必要时在推广文里致谢。
- 收录前先打开看一眼：`curl -sL -o /dev/null -w "%{http_code}" <地址>` 是 200 且页面里能看到 `qb-nav`，才算真正装上了。

## 这些信息用来做什么

只用来填这张表。不做统计、不发邮件、不加任何追踪参数。

主题代码本身也没有埋点：全部逻辑在 `snippets/footer-script-v7.html`，你可以搜一遍，没有任何请求是发往作者这边的。走 jsDelivr 镜像时下载量会计入 [jsDelivr 的公开统计页](https://data.jsdelivr.com/v1/stats/packages/gh/zsy0216/cnblogs-document-theme)，
那是 jsDelivr 自己的计数，不是我加的追踪 —— 而且只有「直接引用作者仓库」的人会被算进去，fork 之后自己发版的统计不到。
