# 移动端与阅读体验（v7.21）

这一批功能都围绕同一件事：**读者在哪里、用什么设备看，都不该缺东西**。
手机上没有目录、宽表被压成竖条、代码铺满三屏、关掉页面就忘了读到哪 —— 这些不是美化，
是功能缺口。

## 一、移动端目录抽屉

### 为什么做

`<860px` 时 `#qb-left` 整列 `display:none`，手机上**完全没有目录**。
博客园自带的「显示目录导航」按钮（`.cnblogs-toc-button`）只是每个标题旁边一个小图标，
点开是平台自己的一层浮层，样式与本主题脱节。v7.21 起一律藏掉，换成自己的抽屉。

### 怎么做的

- 左下角一个 44px 高的胶囊按钮（`#qb-mtoc-fab`），文字「目录」+ 三横线图标；
  右下角是原有的「回到顶部」，两端分开，互不遮挡。
- 点开是底部抽屉：遮罩 + 圆角面板，最高 `76vh`，内容可滚。
- 内容**从桌面目录克隆**（`#qb-left .qb-toc-list a[data-t]`），不重新扫标题。
  这样桌面和手机看到的是同一份目录，不会出现「桌面有 H4、抽屉没有」的两套逻辑。
- 点击条目：关闭抽屉 → 平滑滚到标题（减去 64px 顶栏）→ `history.replaceState` 更新锚点。
- 高亮自己算：桌面那套 spy 绑在 `#qb-left` 的滚动容器上，手机上左栏不显示，
  它照样在跑但用户看不到；抽屉里另有一份按标题位置的 spy。
- 滚动锁加在 `html` 上（`html.qb-mtoc-lock`）。iOS 对 `body { overflow:hidden }` 不生效，
  锁 body 等于没锁。
- 窗口拉宽越过 860px 时，`matchMedia` 的 change 会调 `close()`：否则抽屉被 CSS 藏了，
  `html` 上的滚动锁还在，桌面端整页不能滚。

### 其它移动端调整

| 位置 | 调整 |
|:---|:---|
| `≤480px` | 正文 16px / 行高 1.85（15px 在 375 宽上偏挤） |
| `≤480px` | 左右留白各收 4px，有效宽度 +8px；标题降到 20px |
| `≤480px` | 标题旁的锚点 `#` 隐藏（触屏没有 hover，常驻的 `#` 只是噪音） |
| `≤860px` | 宽表单元格 `min-width: 84px`、字号 12.5px；代码折叠高度 360px |
| `≤860px` | 悬浮按钮与回到顶部都带 `env(safe-area-inset-bottom)`，避开 iPhone 底部横条 |

## 二、宽表格：横向滚动 + 首列吸附

### 问题

博客园给正文表格写死 `width: 100%`。七列表格在 780px 正文里每列只剩 110px，
「操作」「说明」这类表头被折成两行，看起来像排版坏了。

### 做法

1. 脚本给每个 `table` 套一层 `.qb-table-wrap`（`overflow-x: auto`）。
2. 单元格给下限宽度（桌面 92px / 手机 84px）。撑不下时表格自然超出容器 → 横向滚动。
3. 首列 `position: sticky; left: 0`。左右滑动时首列留在左边，才知道当前这行是哪个接口。
4. 只有**真的溢出**才加 `.qb-x`：不溢出的窄表也吸附，会多出一条竖线，看着像被裁了一角。
5. 首列的右侧分隔用 `box-shadow` 而不是 `border-right`：border 会加宽单元格，
   横滑时首列宽度跳一下。
6. 触屏没有可见滚动条，`.qb-x` 在 `@media (hover: none)` 下给右侧 26px 渐隐，提示还能往右滑。

> 判断溢出用 `scrollWidth - clientWidth > 2`，并在 `resize`、`load`、`ResizeObserver`
> 三处更新：表格里的图片、字体变化都会改宽度。

## 三、超长代码块折叠

- 阈值 **34 行**（`FOLD_LINES`）。按行数而不是像素：同一个值在任何字号下都约等于一屏半，
  像素阈值在手机上会把 20 行也折了。
- 折叠高度 500px（手机 360px），底部一条按钮写「展开全部（共 N 行）」。
- 按钮放在代码块**底部**而不是顶部工具条：读者滚到折叠处才发现被截断，
  再滚回顶部找按钮等于白折。收起时若按钮已滚出视口，会把块顶部拉回来。
- 按钮上方 64px 渐隐，盖住被切断的最后半行 —— 直接一刀切会正好切在字符中间。
- 打印时 `max-height: none`：纸上没有「展开」可点，必须整段印出来。

## 四、续读记忆

按「路径」把滚动位置存进 `localStorage`，下次进同一篇自动回到那儿，并给一条可撤销提示。

键名：`qb-pos:<pathname>`，值 `{ y, h, t }`。

几个克制的边界（都是为了避免「帮倒忙」）：

| 条件 | 行为 | 原因 |
|:---|:---|:---|
| 页面高度 < 1200px | 不记录 | 短页没有「上次位置」可言 |
| 滚动位置 < 300px | 清除记录 | 回到顶部 = 读完了 / 不打算续读 |
| 带 `#hash` 进来 | 不恢复 | 那是有明确目标的跳转，抢过来就是错误 |
| 页面已滚动 > 120px | 不恢复 | 读者已经自己动了，别把他拽走 |
| 记录超过 7 天 | 丢弃 | 文章可能改过，位置不可信 |
| 记录超过 60 条 | 按时间删到 40 条 | 避免 localStorage 越攒越多 |

恢复时机在 `load` 之后 60ms：图片与字体把页面撑到最终高度后再滚，位置才对得上。
`pagehide` 与 `visibilitychange` 都会补写一次，手机切后台直接杀进程也不会丢。

## 五、暗色跟随系统

原来只在加载时读一次 `prefers-color-scheme`。页面开着的时候系统切暗色
（macOS 日落自动切、Windows 定时切），主题一动不动，得手动刷新。

现在订阅 `matchMedia('(prefers-color-scheme: dark)')` 的 `change`。
优先级不变：**读者手动选过（`localStorage` 有值）就永远不跟系统** ——
那是明确的选择，不能被系统顶掉。

## 六、Markdown 元素补全

园方只给了 `p / h* / pre / table` 的样式，下面这些全是浏览器默认外观，
夹在正文里像「另一个网站的片段」。v7.21 补齐：

| 元素 | 处理 |
|:---|:---|
| `kbd` | 双层下边框模拟键帽，等宽字体，`.82em` 不撑行高 |
| `mark` | 黄色半透明底；暗色换成低亮琥珀，不然白底黄字刺眼 |
| `details / summary` | 边框圆角卡、自定义 ▸ 三角、展开旋转 90° |
| 任务列表 | 脚本给 `li` 加 `.qb-task`、父列表加 `.qb-tasklist`，去掉圆点、复选框负缩进对齐 |
| 脚注 | `sup a` 强调色、文末 `.footnotes` 上边框分隔 |
| `figure / figcaption` | 居中说明文字 |
| `dl / dt / dd` | 术语加粗、定义缩进 |
| `abbr[title]` | 虚线下划线 + help 光标 |
| `hr` | 1px 分隔线（原来是浏览器默认的立体槽） |

任务列表必须由脚本打标记：Markdown 渲染器输出的是 `<li><input type=checkbox>`，
园方仍给 `li` 画圆点，于是每行前面「• ☐」。纯 CSS 要 `:has()`，老内核不支持。

## 七、打印 / 存 PDF

`@media print` 做四件事：

1. **变量归零**：正文颜色都走 CSS 变量，在打印媒体里把 `--bg/--ink/--pre-*` 全改成
   白底深字，比逐条覆盖几十个选择器省事。暗色模式也一起压平。
2. **去掉外壳**：顶栏、左栏、右栏、回到顶部、目录抽屉、代码工具条、折叠按钮、
   评论区、上下篇、标签、归档索引全部 `display:none`；`#main` 改 `display:block`。
3. **代码整段展开、自动折行**：`max-height:none`、`white-space:pre-wrap`。
   同时把 Prism 的 token 颜色强制成深色 —— 那套配色是按深色底设计的，印在白纸上
   是浅橙 / 浅黄，几乎看不见。
4. **Prism 行号在打印里关掉**：它的行号容器是 `position:absolute`、一行一个 span 定高；
   纸上开 `pre-wrap` 后长行一折就比行号多占一行，后面的编号整体错位。
   宁可这页不印行号，也不能让读者按错位的编号对照代码。
   主题自建的 `.qb-cl::before` 是跟着块走的，折行不会错位，保留。

表格在打印时去掉 `overflow`、`min-width` 与 sticky，回到文档流按纸张宽度排版。
