# 给博客园换一身「文档站」皮肤：一个三栏 + 暗黑模式的开源主题

> 仓库：<https://github.com/zsy0216/cnblogs-document-theme>
> 技术栈：纯 CSS（Grid）+ 原生 JS，零依赖、零构建、零后端

## 一、为什么想换皮

博客园自带的皮肤，基本都是「博客时间线」审美：正文居中、侧栏堆在右边、区块之间靠缩进和分割线区分。

写技术笔记的时候，这套版式有三个明显的不顺手：

1. **长文没有目录**。文章一长，只能靠滚动条硬扛，回头找某一节要翻半天。
2. **侧栏和正文挤在一起**。公告、搜索、常用链接全堆在同一列，视觉噪音比信息还多。
3. **没有暗色**。晚上看白底文章，眼睛是真的累；自己写 CSS 又容易和园方样式打架。

于是我按「文档站」（类似 VitePress / Docusaurus）的版式思路，把博客园重写了一遍。所有选择器都对着 2026 年 11 月博客园真实 DOM 校准过，不再假设不存在的节点。

## 二、长什么样

**首页**：左中右三栏，左边是全文文章列表，中间是文章卡片，右边是公告和常用链接。

![首页效果](https://cdn.jsdelivr.net/gh/zsy0216/cnblogs-document-theme@master/docs/images/home-v7.png)

**文章页**：左边是正文 H1–H4 自动生成的目录，右边是卡片式侧栏，正文独占中栏。

![文章页效果](https://cdn.jsdelivr.net/gh/zsy0216/cnblogs-document-theme@master/docs/images/post-v7.png)

**暗色模式**：配色对齐 GitHub Dark —— 底色 `#0d1117`、卡片 `#161b22`、描边 `#30363d`、正文 `#c9d1d9`。不是简单把白底刷黑，而是每个层级都重新定了一套色。右上角 🌙 一键切换，状态存本地，首次访问跟随系统偏好。

![暗色首页](https://cdn.jsdelivr.net/gh/zsy0216/cnblogs-document-theme@master/docs/images/home-v7-dark.png)

## 三、都做了哪些事

### 1. 三栏布局：纯 CSS，不动一行 HTML

博客园的 DOM 结构是 `#main` 里塞 `#mainContent` 和 `#sideBar`。想做成三栏，常规做法是 JS 搬节点，但那样每次刷新都会闪一下。

这里用的是 Grid，而且**一个节点都不搬**：

```css
#main {
  display: grid;
  grid-template-columns: 260px minmax(0, 1fr) 292px;
  gap: 22px;
}
#sideBar { display: contents; }   /* 只摊平外面那层壳 */
#sideBarMain { grid-column: 3; }  /* 博客园自带的侧栏容器，原地当右栏 */
#qb-left      { grid-column: 1; } /* 左栏由脚本新建：文章列表 / 目录 */
#mainContent  { grid-column: 2; } /* 中：正文 */
```

关键在于**不做 DOM 搬运**。早期版本用 JS 把侧栏卡片搬进自建容器，结果每次刷新都要闪一下；现在右栏直接用博客园自己的 `#sideBarMain`，卡片本来就在里面，一个节点都不动。右栏内容晚到只会改变它自己的高度，推不动正文和左栏——这是「切页不抖」的结构性原因。

断点也很好写：≤1024px 收成两栏（隐藏右栏），≤860px 单栏。

### 2. 左栏目录：按页面类型自动切换

同一个左栏，在不同页面显示不同内容：

| 页面 | 左栏内容 |
|:---|:---|
| 首页 | 全部文章标题 + 日期 |
| 文章详情 | 正文 H1–H4 目录（点击跳转） |
| 分类 / 标签 / 归档 | 分类名 / 标签名 / 月份 |

逻辑很简单：进入页面 → 左栏拿到什么就渲染什么，正文里有标题就写目录，没有标题就写文章列表。没有额外请求，也没有额外配置。

### 3. 暗黑模式：一套变量，全局换肤

整个主题的配色都走 CSS 变量，暗色只需要覆盖变量值：

```css
body.qb-dark {
  --bg:     #0d1117;
  --card:   #161b22;
  --line:   #30363d;
  --ink:    #e6edf3;
  --body:   #c9d1d9;
  --meta:   #8b949e;
  --accent: #58a6ff;
}
```

右上角的 🌙 按钮切换，状态存在 `localStorage`，刷新不丢；首次访问会跟随系统的 `prefers-color-scheme`。

值得一提的是，博客园有些原生区块（公告、评论框、代码块）自带内联浅色，光靠变量覆盖不掉。这部分单独写了层暗色补丁，把它们压成半透明深底，保证整页没有「白块残留」。

### 4. 顺手修的几个老问题

- **回到页首**：滚动超过 300px 出现，点击平滑回顶
- **列表页统一卡片化**：分类页、标签页、归档页不再是裸列表，跟首页一个观感
- **右侧「搜索」标题被压成竖排**：`flex` 布局下 `white-space` 没锁住，两行挤成一列字，加 `flex-shrink: 0` 解决
- **favicon 接管**：见下一节

### 5. favicon：一个被很多人踩过的坑

博客园的「页首 HTML 代码」并不是插到 `<head>` 里，而是塞在 **body 里的 `#page_begin_html`** 容器中。而浏览器只认 `<head>` 里的 `<link rel="icon">` —— 所以你往页首贴 favicon，**基本不会生效**。

更麻烦的是两件事：

1. 博客园 `<head>` 里本来就写死了 `favicon_v3_3.ico` 和 `.svg` 两个默认图标，你追加一个，就变成三个图标并存，浏览器爱用哪个用哪个；
2. 园方脚本在页面加载完几秒后，还会再往 `<head>` 里补一次默认图标。

所以主题脚本干了三件事：把用户图标搬进 `<head>`、清掉所有非用户图标、用 `MutationObserver` 持续拦截后续插入。搬完 check 一遍，`<head>` 里只剩你设置的那一个。

### 6. 切页不抖：三处 1~2 像素的账

版式对了不代表观感对了。逐帧录屏（CDP screencast，按每帧 jpeg 字节数判空白）才发现，切页时还有三处不该有的跳变：

| 现象 | 根因 | 修法 |
|:---|:---|:---|
| 顶栏从离顶部 8px 处弹回 0 | 浏览器给 `<body>` 的**默认边距**，在样式到位前一直存在 | 首帧样式里 `html,body{margin:0}` |
| 顶栏塌成一条线再张开 | 页首里的顶栏是外层 div，撑高度的内层还没解析到时高 0 | `.qb-nav{min-height:58px}` |
| 整页先按园方皮肤画一遍再换肤 | CSS 在 js 里，脚本没到就没有样式 | 完整样式放回「页面定制 CSS」字段，js 检测到标记就跳过注入 |

再加上跨文档视图过渡（`@view-transition`）给顶栏单独命名、两张快照强制不透明，切页过程空白帧从 **3 帧降到 0 帧**，`nav.height` 全程恒为 59px。

不支持跨文档视图过渡的浏览器（如 Firefox）会忽略这几条规则，退回普通导航，不会更差。

## 四、怎么装（4 步）

> ⚠️ 第 0 步最重要：**设置 → 皮肤 → 选 `Custom`（自定义）**，否则后面全都不生效。

样式和逻辑都走托管，后台只填两个字段、传一个文件：

1. **先清空页脚与公告**：两个字段全选删除。这一步不能省 —— 页脚里若残留旧版内联脚本，它会自己建一套右栏，和新版同时跑
2. **页面定制 CSS 代码** → 全选替换为 `dist/paste/样式.css`（32 KB，完整样式 + 首帧标记）
3. **页首 HTML 代码** → 全选替换为 `dist/paste/页首.html`（2.2 KB，配置 + 加载器）
4. **文件 → 上传** `dist/document-theme.js`（70 KB），覆盖同名旧文件

保存后前台 `Ctrl+F5` 强刷。

之后改样式或改逻辑，只需要重传第 3 步那个文件，不用再动后台。

顶栏菜单、公告文案、强调色都不必改源码，页首那段 `window.LS_CONFIG` 里配就行：

```js
window.LS_CONFIG = {
  accent: '#d05ce8',
  nav: {
    brand: '你的博客名',
    links: [
      { t: '首页', h: 'https://www.cnblogs.com/你的博客名/' },
      { t: '归档', h: 'https://www.cnblogs.com/你的博客名/p/archive/2026/11' },
      { t: 'GitHub', h: 'https://github.com/zsy0216', b: 1 }   // b:1 = 新窗口
    ]
  },
  notice: { show: true, title: '公告', html: '<p>写点什么</p>' }
};
```

**回滚**：清空「页面定制 CSS」「页首 HTML」「页脚 HTML」三个字段，就恢复默认外观。旧版 v6.28 已封存在 tag `v6.28`，需要时从仓库取出重贴。

## 五、几个设计取舍

**为什么不用框架？** 博客园的自定义代码是直接贴进页面的，没有构建流程。引入 Vue/React 意味着要么上 CDN（多一个外部依赖、多一次阻塞），要么把运行时整个贴进去（几十 KB）。这个主题的交互只有「切暗色」「回顶」「生成目录」三件小事，原生 JS 加起来不到 10KB，没必要。

**为什么 CSS 要分全版和压缩版？** `theme-v7.css` 是带完整注释的开发版，`theme-v7.min.css` 是发布版（体积小 45%）。博客园的 CSS 字段有长度限制，压一下更安全。

**为什么强调「对着真实 DOM 写」？** 网上很多博客园美化代码是几年前的，选择器早就失效了，贴上去一半样式不生效，还容易和园方新样式打架。这个主题的每条选择器我都在线上页面验证过。
